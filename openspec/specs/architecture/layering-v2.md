# Devrix 五层架构 ID 规范 (v2)

**Status:** Proposed
**Version:** 2.0.0
**Last Updated:** 2026-06-08
**Supersedes:** `layering.md`

---

## 概述

本文档定义 Devrix 的五层 ID 分层规范，用于：
1. **唯一标识**所有业务能力
2. **可追溯性**从领域到测试点
3. **导航性**快速定位代码和文档

---

## 五层 ID 结构

```
{D}-{S}-{A}-{F}-{T}
  │   │   │   │   └── T: 测试点 (Test Point)     01-99
  │   │   │   └────── F: 功能点 (Feature Point)   01-99
  │   │   └────────── A: 业务活动 (Activity)      01-99
  │   └────────────── S: 场景 (Scenario)         01-99
  └────────────────── D: 领域 (Domain)           01-99
```

### 示例

```
COMM-S01-A01-F01-T01
  │    │   │   │   └── 测试点: 验证网关会话创建成功
  │    │   │   └────── 功能点: 会话管理
  │    │   └────────── 业务活动: 网关路由
  │    └────────────── 场景: 飞书接入
  └────────────────── 领域: 通信
```

## Layer 1: Domain (D) - 领域层

**格式**: `D{01}-{name}`
**命名规则**: 全大写，2-4 字符英文缩写

| ID | 名称 | 英文 | 描述 |
|----|------|------|------|
| D01 | 通信域 | COMM | 用户交互、消息路由、会话管理 |
| D02 | 上下文域 | CTX | 上下文压缩、PEV 引擎、记忆管理 |
| D03 | LLM 网关域 | LLM | 模型适配、熔断、重试 |
| D04 | 多智能体域 | AGENT | Agent 生命周期、Fork/Join、权限 |
| D05 | 可观测域 | OBS | 追踪、指标、日志 |
| D06 | 演化域 | EVO | 版本管理、配置热更新 |

## 代码注释规范

```go
// D01-S04-A01-F01: 创建新会话
// D02-S01-A02-F06-T01: Autocompact 降级测试
func (s *SessionManager) Create(...) error {
    // D01-S04-A01-F01-T01: 验证输入
    if req.ProjectID == "" {
        return ErrInvalidProject
    }
    
    // D01-S04-A01-F01-T02: 创建会话实例
    session := newSession(...)
    
    // D01-S04-A01-F03: 持久化存储
    if err := s.store.Save(session); err != nil {
        return fmt.Errorf("D01-S04-A01-F03: %w", err)
    }
    
    return nil
}
```
